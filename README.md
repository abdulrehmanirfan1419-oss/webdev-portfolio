# Abdul Rehman — Web Developer Portfolio

A premium dark, responsive portfolio site built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for the Pages deployment to complete. The expected URL is:
   https://abdulrehmanirfan1419-oss.github.io/webdev-portfolio/

## Portfolio notes
